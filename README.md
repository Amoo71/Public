# CLI Lite (v3) — config-driven hub + downloads

Edit `config.json` to point to **your own** hub domains and your allowed download/CDN domains.

## Run
```bash
npm install
npm start
```
Open http://localhost:3000

## Deploy (Render)
Build: `npm install`
Start: `npm start`
Change `config.json` in your repo to update domains and redeploy.
